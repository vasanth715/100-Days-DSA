# 🔤 Strings — DSA Pattern Guide

Strings are sequences of characters.

This folder contains problems where the main operation is performed
on characters, substrings, prefixes, or complete strings.

---

## 🧠 How to Identify a String Problem

Look for keywords such as:

- String
- Character
- Substring
- Subsequence
- Prefix
- Suffix
- Palindrome
- Anagram
- Frequency
- Compare strings
- Reverse string
- Remove characters
- Replace characters
- Concatenate strings
- Pattern matching

---

# 🔑 Important String Keywords

| Keyword | Think About |
|---|---|
| Palindrome | Two Pointers |
| Reverse | Two Pointers / Traversal |
| Anagram | HashMap / Frequency |
| Frequency | HashMap / Array |
| Prefix | Start of string |
| Suffix | End of string |
| Substring | Continuous characters |
| Subsequence | Characters in order, not necessarily continuous |
| Character count | HashMap / Frequency Array |
| Unique characters | HashSet |
| Compare characters | Two Pointers / Traversal |
| Concatenate | String building |
| Replace characters | Traversal / Greedy |
| Matching pattern | String traversal / HashMap |
