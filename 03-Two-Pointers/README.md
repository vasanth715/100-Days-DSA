# 👉 Two Pointers — DSA Pattern Guide

Two Pointers is a technique where we use two indexes/pointers
to process an array or string efficiently.

Instead of repeatedly scanning the same elements,
we move pointers according to the problem's conditions.

---

# 🧠 How to Identify Two Pointers

Look for keywords such as:

- Two ends
- Beginning and end
- Left and right
- First and last
- Compare both sides
- Reverse
- Palindrome
- Pair
- Sorted array
- Move elements
- In-place
- Opposite directions
- Slow and fast
- Remove duplicates
- Partition
- Rearrange

---
